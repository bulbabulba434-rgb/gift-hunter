# 🎁 Gift Hunter — охотник за редкими NFT-подарками Telegram

Каждые ~10 минут бот смотрит маркет перепродажи подарков Telegram и присылает тебе в личку лоты, которые выглядят недооценёнными:

- **редкие атрибуты почти по цене флора.** Модель, фон или символ встречаются у ≤1% подарков коллекции и заметно реже типичных;
- **дешевле аналогов.** Лот на 15%+ дешевле следующего такого же (та же модель, без дополнительных редких атрибутов);
- **флор с отрывом.** Самый дешёвый лот коллекции заметно дешевле второго;
- **низкий номер** (#1–#100).

К каждой находке Gemini пишет короткий вердикт («брать / присмотреться / пропустить») и главный риск. Telegram добавляет свою статистику: среднюю цену и последнюю продажу.

> ⚠️ Это подсказки алгоритма, а не финансовый совет. Перед покупкой проверяй лот сам: бот ничего не покупает.

Всё бесплатно: Telegram API, Bot API, Gemini API (бесплатный лимит) и GitHub Actions (бесплатно для публичных репозиториев).

## Что понадобится (≈15 минут)

| Что | Где взять |
|---|---|
| `TG_API_ID`, `TG_API_HASH` | https://my.telegram.org → API development tools → создать приложение (название любое) |
| `TG_SESSION` | команда `python -m hunter login` (ниже) |
| `BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` |
| `CHAT_ID` | команда `python -m hunter chatid` (ниже) |
| `GEMINI_API_KEY` | https://aistudio.google.com/apikey → Create API key (бесплатно; можно не указывать, тогда без ИИ-комментариев) |

> 🔐 **Лучше завести второй Telegram-аккаунт** и логиниться им. Маркет подарков читается только через пользовательский аккаунт, а `TG_SESSION` даёт полный доступ к аккаунту, к которому относится. Никому её не показывай и не клади в код: только в `.env` и GitHub Secrets.

## Шаг 1. Установить и проверить на своём ПК

```bash
pip install -r requirements.txt
```

```bash
python -m hunter demo
```

`demo` гоняет логику на выдуманных данных, без Telegram: так видно, как выглядят уведомления.

## Шаг 2. Получить ключи

1. Скопируй `.env.example` в `.env`.
2. Впиши `TG_API_ID` и `TG_API_HASH`, затем выполни:
   ```bash
   python -m hunter login
   ```
   Введи api_id, api_hash, номер телефона и код из Telegram. Скопируй длинную строку в `.env` как `TG_SESSION=...`.
3. Создай бота у @BotFather и впиши `BOT_TOKEN`. Напиши своему боту `/start` и выполни:
   ```bash
   python -m hunter chatid
   ```
   Впиши полученный `CHAT_ID`.
4. По желанию впиши `GEMINI_API_KEY`.
5. Проверь настоящий скан:
   ```bash
   python -m hunter run
   ```

Хочешь, чтобы бот работал прямо с ПК и отвечал на команды мгновенно? Запусти `python -m hunter loop`.

## Шаг 3. Бесплатный сервер на GitHub Actions

1. Создай на https://github.com **публичный** репозиторий. Для публичных репо минуты Actions бесплатны без лимита; секреты в них всё равно никто не видит.
2. Загрузи туда все файлы проекта, **кроме `.env`**: «Add file → Upload files», можно перетащить папку целиком вместе с `.github`. Или через git.
3. Открой Settings → Secrets and variables → Actions → New repository secret и добавь по одному: `TG_API_ID`, `TG_API_HASH`, `TG_SESSION`, `BOT_TOKEN`, `CHAT_ID`, `GEMINI_API_KEY`.
4. Во вкладке Actions включи workflows, если GitHub спросит. Затем выбери «gift-hunter → Run workflow», чтобы проверить первый запуск.

Дальше скан идёт сам каждые ~10 минут. GitHub иногда запускает по расписанию с опозданием на 5–15 минут, это нормально.

## Команды бота

| Команда | Что делает |
|---|---|
| `/top` | лучшие находки последнего скана |
| `/budget 5000` | искать только лоты до 5000 ⭐ (`/budget off` снимает лимит) |
| `/pause`, `/resume` | выключить или включить уведомления |
| `/status` | когда был последний скан и сколько всего найдено |

На GitHub Actions бот отвечает на команды при следующем скане, то есть с задержкой до ~10 минут. В режиме `loop` на ПК отвечает сразу.

## Настройка

Все пороги лежат в [config.yaml](config.yaml): лимит цены, что считать «редким», минимальная скидка, конкретные коллекции. Если уведомлений слишком много, подними `min_score`; если мало, опусти.

## Как это устроено

```
hunter/
  market.py   чтение маркета через Telegram MTProto (Telethon)
  scoring.py  поиск сделок: редкость, отрыв от аналогов, флор, номер
  ai.py       комментарий Gemini
  bot.py      отправка сообщений и команды бота
  app.py      скан → оценка → уведомления; state/ хранит уже показанные лоты
```

Тесты: `python -m unittest discover -s tests -t .`
